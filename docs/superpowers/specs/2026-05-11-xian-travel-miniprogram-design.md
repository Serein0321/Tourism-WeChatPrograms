# 西安文旅微信小程序 UI 静态稿设计

## 目标

开发一个面向旅客的西安文旅微信小程序静态原型，用于展示信息漫游、智能规划、旅行社区和个人中心四个核心入口。第一版重点交付可运行、可预览的 UI 页面结构，不接入后端、地图 SDK 或真实实时数据。

## 范围

本次交付内容：

- 4 个底部 Tab：信息漫游、智能规划、旅行社区、个人中心。
- 智能规划相关二级页：商品推荐、商品对比、路线规划、历史客流、节假日预测、导入平台行程。
- 个人中心相关二级页：订单、最近浏览、我的收藏、我的行程、发帖、评价打分、分享。
- 所有页面使用静态模拟数据和渐变占位图。
- 点击入口可以跳转到对应二级静态页。

不包含内容：

- 不接入真实后端。
- 不接入地图 SDK。
- 不实现真实 2D/3D 地图渲染。
- 不实现实时住宿、交通、美食、景点、公共设施数据。
- 不实现复杂拖拽式上滑面板或真实算法推荐。

## 信息架构

底部导航包含四个主入口：

1. 信息漫游
2. 智能规划
3. 旅行社区
4. 个人中心

信息漫游作为第一页，突出西安风景和城市文化体验。智能规划作为第二页，展示地图式规划、圈层分类、点位和下方规划入口。旅行社区承接发帖、评价打分和分享能力，展示游记、攻略和行程动态。个人中心展示用户资产、订单、浏览、收藏和行程入口。

## 页面设计

### 信息漫游

页面内容包括：

- 西安欢迎区，突出“古都西安”“城市漫游”等文案。
- 渐变风景轮播，用于模拟美景照片自动切换。
- 漫游推荐卡片，例如城墙晨光、钟鼓楼夜景、大唐不夜城、秦岭山水。
- 用户体验模块，包含“自动切换美景”“导入本地照片”等静态入口。

### 智能规划

页面内容包括：

- 顶部目的地搜索区。
- 西安地图占位区。
- 不同颜色点位，分别表示住宿、交通、美食、景点、公共设施。
- 多主题圈层卡片：住宿、交通、美食、景点、公共设施。
- 弹窗信息样式卡片，用于表达点位详情。
- 底部规划面板，包含搜索标签和功能宫格：商品推荐、商品对比、路线规划、历史客流、节假日预测、导入平台行程。

### 旅行社区

页面内容包括：

- 发帖入口。
- 西安游记卡片。
- 评价打分卡片。
- 行程分享卡片。
- 攻略标签，例如亲子、夜游、历史文化、美食路线。

### 个人中心

页面内容包括：

- 用户信息卡。
- 订单入口。
- 最近浏览入口。
- 我的收藏入口。
- 我的行程入口。
- 常用服务入口。

## 二级页面

智能规划相关页面：

- 商品推荐：展示西安景点、餐饮、住宿或体验商品卡片。
- 商品对比：展示多个商品的价格、评分、距离、推荐理由对比。
- 路线规划：展示一日游、两日游、夜游等路线卡片。
- 历史客流：展示静态客流趋势、热门时段和建议错峰信息。
- 节假日预测：展示节假日热度预测、拥挤等级和推荐时间。
- 导入平台行程：展示从其他平台导入行程后的静态路线生成结果。

个人中心相关页面：

- 订单：展示待出行、已完成、退款售后等订单卡片。
- 最近浏览：展示最近看过的景点、路线、商品。
- 我的收藏：展示收藏的景点、美食、路线。
- 我的行程：展示行程列表，并提供发帖、评价打分、分享入口。
- 发帖：提供静态发布表单 UI。
- 评价打分：提供星级评分、标签和输入框 UI。
- 分享：提供分享卡片和分享渠道 UI。

## 视觉风格

整体风格为清新西安旅游感：

- 背景：浅米白、淡蓝、浅绿。
- 主色：自然绿、天空蓝。
- 辅色：暖橙，用于表达古都文化和重点按钮。
- 组件：圆角卡片、胶囊标签、轻阴影、渐变图片占位块。
- 图片策略：不使用外网图片，使用 CSS 渐变模拟西安风景照片，后续可替换为真实素材。

## 数据与交互

- 数据来源全部为前端静态模拟数据。
- 页面跳转使用微信小程序原生导航。
- Tab 切换使用小程序 tabBar。
- 弹窗、筛选、导入、分享等功能以静态 UI 表达为主。
- 70% 自动切换或导入美景照片在本版中表现为轮播/提示入口，不实现真实图片识别或自动切换算法。

## 技术实现

使用微信小程序原生技术栈：

- WXML：页面结构。
- WXSS：视觉样式。
- JS：静态数据和基础跳转。
- JSON：页面配置和导航配置。

项目应能在微信开发者工具中直接运行预览。

## 验收标准

- 小程序可以在微信开发者工具中打开并预览。
- 底部四个 Tab 可正常切换。
- 每个主页面都有完整静态 UI。
- 智能规划和个人中心相关二级页可从入口跳转打开。
- 页面内容围绕西安旅游场景。
- 页面不依赖外网图片或真实接口。
- 视觉风格统一，符合清新旅游感。
