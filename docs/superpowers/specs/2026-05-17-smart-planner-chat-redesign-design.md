# 智能规划页对话式改版设计（A 方案）

日期：2026-05-17

## 1. 背景与目标

当前智能规划页以卡片工具聚合为主，缺少明显的对话入口与沉浸式交互。目标是将页面改为“地图在上 + 对话面板在下”的结构，并强化智能体对话体验。

本次改造目标：
- 将页面正上方改为真实地图组件预留位（当前无 SDK，先空态占位）。
- 将底部改为可上滑展开的对话面板，默认半开。
- 提供醒目的“打开智能体对话”入口按钮，并具备打开动画。
- 展开态左上角提供“< 新对话”并支持会话重置。
- 将输入框上方功能标签固定为：商品推荐、商品对比、路线规划、历史客流、节假日预测、导入平台行程。
- 删除原“多主题圈层/多主体圈层”模块及相关视觉。

## 2. 设计范围与非目标

范围内：
- pages/planner/planner.wxml 结构重构。
- pages/planner/planner.js 状态与交互重构。
- pages/planner/planner.wxss 视觉与动画重构。

非目标：
- 不接入真实地图 SDK（仅预留容器与状态位）。
- 不引入后端对话服务（先本地消息流与演示回复）。
- 不改动其他页面的业务逻辑。

## 3. 信息架构与布局

页面自上而下三层：
1) 地图层
- 顶部区域为 map-shell，占据页面上方主要视觉区。
- 当前显示“地图组件待接入”空态提示，后续可直接替换为地图 SDK 组件。

2) 地图轻量浮层
- 在地图层内保留轻量提示文案，不使用多点位圈层样式。

3) 对话面板层
- 默认半开（collapsed），高度约 40% 屏幕。
- 全开（expanded）高度约 90% 屏幕。
- 顶部包含短横线（grabber）暗示上滑。

## 4. 关键交互设计

### 4.1 面板状态机
- collapsed：默认半开。
- expanded：上滑/按钮打开后的全开。
- transitioning：过渡态，防止重复触发。

切换规则：
- 点击打开按钮：collapsed -> expanded
- 上滑超过阈值：collapsed -> expanded
- 下滑超过阈值：expanded -> collapsed

### 4.2 打开动画
- 打开按钮点击反馈：缩放轻动效（约 120ms）。
- 面板上滑展开：位移动画（约 320ms，ease-out）。
- 消息区内容淡入（约 180ms）。

### 4.3 新对话交互
- 展开态左上角显示“< 新对话”。
- 点击后：
  - 清空消息列表并回到欢迎消息。
  - 清空输入草稿。
  - 保留当前已选功能标签。

### 4.4 功能标签交互
固定标签：
- 商品推荐
- 商品对比
- 路线规划
- 历史客流
- 节假日预测
- 导入平台行程

行为：
- 点击标签切换高亮。
- 可向输入框插入建议前缀。
- “导入平台行程”可在后续版本扩展为跳转既有页面入口。

## 5. 组件与数据模型

## 5.1 WXML 区块
- map-shell：地图占位容器。
- agent-panel：对话主容器。
- panel-header：含 grabber 和“< 新对话”。
- message-list：消息流。
- tool-tabs：标签行。
- chat-composer：输入与发送。
- open-agent-btn：半开态醒目按钮。

## 5.2 JS 数据结构
- panelState: collapsed | expanded | transitioning
- tools: string[]
- activeTool: string
- messages: { role, text }[]
- draft: string
- touchStartY: number
- mapStatus: placeholder | ready | error

## 5.3 核心方法
- openAgentPanel()
- collapsePanel()
- expandPanel()
- onPanelTouchStart()
- onPanelTouchEnd()
- onSelectTool()
- onInput()
- onSend()
- startNewChat()

## 6. 视觉方向

- 采用青绿 + 天蓝 + 琥珀的轻玻璃风格，不使用紫色主基调。
- 对话面板强调圆角、浮层与层次阴影，突出“可拖拽抽屉”。
- 按钮强调高对比渐变与可点击反馈。
- 保持移动端阅读性：字号分层明确、留白充足。

## 7. 错误与空态策略

- 地图未接入：mapStatus=placeholder，显示空态提示与占位背景。
- 输入为空发送：拦截并给出轻提示。
- 消息过长：消息区域滚动，输入区固定底部。

## 8. 测试与验收标准

核心验收：
- 顶部为地图区域，占位可见。
- 默认半开对话面板，含短横线上滑提示。
- 有醒目打开按钮，点击带动画并展开。
- 展开后左上角显示“< 新对话”并可重置会话。
- 输入框上方标签为 6 个指定项。
- 原多主题圈层模块完全移除。
- 在常见移动端宽度下不出现布局溢出。

手工测试建议：
1. 进入智能规划页，确认默认为半开面板。
2. 点击按钮展开，再下滑收起。
3. 连续快速点击按钮，确认不会异常抖动。
4. 发送消息后点击“< 新对话”，确认会话重置。
5. 切换标签并发送，确认高亮与输入行为正确。
